# Совместимость версий

Сервер npm, bridge и пакет verify выпускаются одним набором и должны иметь одну
версию `X.Y.Z`. Unity Hub Pro выпускается независимо. Полная последовательность,
включая автономную установку, описана в [обновлении](../updating.md).

## Узнать запущенные версии

```bash
npx unity-open-mcp status
npx unity-open-mcp --version
```

При несовместимости сервер показывает предупреждение, но не блокирует
подключение. Для обычного обновления начните с `unity-open-mcp update`, затем
согласованно обновите bridge, verify и привязку npm в MCP-клиенте.

## Обновить открытый проект из окна bridge

В Unity откройте **Tools → Unity Open MCP Bridge → Status → Updates**. Нажмите
**Check latest**, просмотрите **Preview**, затем выберите **Apply**. До
подтверждения предпросмотр не изменяет файлы и показывает проектные и домашние
MCP-конфиги, агентские документы/примеры и шаг bridge + verify.

Домашний конфиг обновляется только тогда, когда `UNITY_PROJECT_PATH` (или
детерминированный порт bridge) однозначно принадлежит открытому проекту и файл
не содержит запись другого проекта. Перед первой записью конфигов и документов
создаётся `.bak`. Bridge и verify обновляются одним запросом Unity Package
Manager. Для embedded/`file:` разработки этот шаг отключён, чтобы не заменить
локальный чекаут. После применения дождитесь перезагрузки Unity, перезапустите
MCP/ИИ-клиент и выполните `status` или `ping`.

Агент может получить тот же план инструментом `unity_open_mcp_upgrade` из
группы `typed-editor`. По умолчанию `dry_run: true`; применяйте с `false` только
после проверки отчёта. Явный `target_version: "X.Y.Z"` позволяет выбрать
опубликованную версию без запроса последней версии в npm.

## Обновить другой проект из чекаута

Для сопровождения нескольких проектов используйте скрипт репозитория:

```bash
node scripts/switch-project-version.mjs /path/to/my-game 1.2.3 --dry-run
node scripts/switch-project-version.mjs /path/to/my-game 1.2.3
```

Он обновляет проектные конфиги и UPM-привязки, но намеренно не изменяет
документы и `$HOME`-конфиги. Для открытого проекта эти поверхности безопасно
обрабатывает окно bridge.

## Совместимость Unity

Bridge и verify требуют Unity 2022.3 LTS или новее, включая Unity 6. Node-сервер
не зависит от версии Editor. Unity Hub Pro имеет отдельную версию и темп
релизов; его обновление не изменяет MCP-конфиги и файлы Unity-проекта.
